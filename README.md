# deslop

Скилл для Claude Code: убирает нейрослоп и клодизмы из русских (и английских)
текстов. Статьи, посты, комментарии, реплики ботов.

Сначала чинит читаемость (одна мысль на предложение, связки словами, без
назывных обрубков), потом вычищает канцелярит, кальки, антитезы «не X, а Y»,
афористичные хвосты, «честно» и прочие маркеры, по которым текст палится как
сгенерированный.

## Установка

```bash
git clone https://github.com/Hakoba/deslop ~/.claude/skills/deslop
```

Вызов: `/deslop` или просто «прогони через deslop».

`examples.md` — пары «черновик модели → правка человека». Замените их своими,
так скилл подстроится под ваш голос.
