# deslop

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![Claude Code skill](https://img.shields.io/badge/Claude%20Code-skill-D97757)
![Language: RU / EN](https://img.shields.io/badge/lang-RU%20%2F%20EN-blue)

Скилл для [Claude Code](https://docs.anthropic.com/en/docs/claude-code), который
переписывает текст модели так, чтобы он читался как речь живого человека.
Заточен под русский язык.

## TL;DR

Даёте тексту `/deslop`, получаете назад тот же текст без нейрослопа. Скилл
разжимает «упакованные» предложения, выкидывает канцелярит и кальки, режет
фирменные приёмы Claude («не X, а Y», эпиграмма в конце абзаца, «честно
говоря», «вот что важно:») и проверяет результат по чек-листу. На выходе
только исправленный текст, без списка изменений.

```text
До:    Расчёт честный: курс по API, комиссия, округление по правилам банка.
       Интерфейс — боль, как и положено.

После: Расчёт настоящий. Курс берётся из API банка, комиссия считается по
       тарифу, округление как в выписке. Интерфейс пока сырой.
```

## Почему отдельно для русского

Большинство «humanizer»-промптов написаны под английский: банят *delve*,
*tapestry* и *it's worth noting*, а русский текст пропускают почти без правок.
У русского нейрослопа свои приметы, и deslop ловит именно их:

- **Канцелярит.** «Осуществляет», «в рамках», «является», «данный»,
  «представляет собой», «позволяет» как связка-заполнитель.
- **Кальки с английского.** «Когда дело доходит до», «делает разницу»,
  «в конечном итоге», «фокусироваться на», «инсайт».
- **Кальки из интерфейсов и README.** «Живая версия» (live version), «Начать»
  (get started), «Возможности» (features).
- **Пустые переходы.** «Таким образом», «Стоит отметить», «Важно понимать»,
  «Давайте разберёмся», «Итак».
- **Грамматика.** Деепричастие, оторванное от подлежащего («используя метод,
  результаты улучшаются»), назывные обрубки вместо предложений.
- **Типографика.** Длинные тире в каждом абзаце, перечисления через двоеточие
  внутри строки.

Английский тоже поддерживается: язык определяется по тексту, банки маркеров
раздельные, и русские кальки в английский текст не переносятся.

## Как работает

Правка идёт слоями, по порядку:

| Слой | Что делает |
|---|---|
| 1. Читаемость | Одна мысль на предложение, у каждого есть подлежащее и глагол, «это» только с понятным референтом, связки словами |
| 2. Русский слоп | Канцелярит, кальки, ложная универсальность, синонимическая карусель, мораль в конце |
| 3. Клодизмы | Антитезы, афористичные хвосты, анафоры, саспенс-двоеточия, «честно», правило трёх, метафоры вроде «живёт» и «несёт» |
| 4. Дискурс | То, по чему палятся агенты в комментариях: отвечают на всё, никогда не пишут «не знаю», всегда оставляют последнее слово |

После правки модель молча проходит чек-лист из 9 вопросов и перечитывает два
случайных абзаца отдельно от текста.

### Режимы

Задаются словом в запросе, иначе определяются по тексту.

| Режим | Для чего | Форма |
|---|---|---|
| `article` | статьи, блоги, лендинги | абзацы разной длины, не больше 2–3 тире на статью |
| `post` | посты в соцсетях и каналах | до ~800 знаков, без подзаголовков |
| `comment` | комментарии, форумы, чаты | 2–4 предложения, без списков; можно «не знаю» |
| `bot` | реплики бота, тексты интерфейса, промпты | 1–2 предложения, без морали |

### Что не трогает

Цитаты, код, команды, имена файлов, цифры. Голос автора: разговорные слова,
самоиронию, кривоватые идиомы. Если текст писала модель, её шутки голосом
автора не считаются и тоже правятся.

## Установка

```bash
git clone https://github.com/Hakoba/deslop ~/.claude/skills/deslop
```

Для одного проекта положите папку в `.claude/skills/deslop` внутри репозитория.

## Использование

```text
/deslop
/deslop comment  <текст>
прогони этот пост через deslop
перепиши по-человечески, звучит как нейронка
```

Скилл подхватывается и сам, когда Claude пишет текст для людей.

## Настройка под себя

`examples.md` содержит пары «черновик модели → правка человека». Модель читает
их перед статьями и постами, чтобы попасть в голос. Примеры в репозитории
условные. Лучше всего заменить их 5–10 парами из своих текстов: что вы
переписали за моделью и почему.

## Структура

```text
deslop/
├── SKILL.md      # инструкции скилла: режимы, слои, чек-лист
├── examples.md   # калибровка голоса, замените своими парами
└── LICENSE
```
